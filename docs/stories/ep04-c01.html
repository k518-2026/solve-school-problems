EPISODE #04 ・ [C01] ⚖️ パターンC：学校法制・教育委員会・学校法務

疑いと報告のあいだ――校長が学ぶいじめ防止対策推進法と重大事態の判断

🏷️ カテゴリ・領域：学校法制・いじめ防止（いじめ防止対策推進法 / 第28条（重大事態の調査） / 第22条（学校いじめ対策組織の設置） / 学校教育法第11条）
👥 登場人物：校長・青木先生（校長就任2年目） × 教育委員会・生徒指導担当指導主事・黒田先生
💡 解決フレームワーク：いじめ防止対策推進法（第28条 重大事態の調査義務、第22条 学校いじめ対策組織）および文部科学省「いじめの重大事態の調査に関するガイドライン」に基づく適法な初動対応

夕闇が迫る校長室で、青木は机の上に置かれた一枚の診断書と、母親からの切実な訴えが綴られた手紙を凝視していた。着任して二年目。市立緑ヶ丘中学校の舵取りを任されて以来、幾多の保護者対応や生徒指導上の懸念に対処してきたつもりだったが、今夜ほど自身の管理職としての足元が揺らいだことはない。

発端は、二年生の男子生徒による連続欠席だった。最初は体調不良という理由だったが、欠席日数が一週間を超えた頃、母親が青木を訪ねてきたのだ。涙ながらに語られた内容は、学校側が把握していた状況とはあまりに乖離していた。登校するたびに特定のグループから下駄箱や教室で執拗に持ち物を隠され、威圧的な言葉を浴びせられているという。心身の苦痛から朝起き上がれなくなり、医師からは適応障害の疑いと診断されていた。

しかし、青木が学年主任の佐藤を呼んで確認したところ、佐藤は腕を組み、どこか面倒くさそうにこう言い放ったのである。
「青木先生、それは違いますよ。あいつらは普段から仲がいいんです。プロレスごっこみたいなノリで、ちょっと小突き合っているだけです。本気でいじめだなんて思っているのは、過保護な親御さんの方ですよ。大げさに騒ぐと、かえって事態がこじれますから、学校で穏便に指導して終わらせます」

「穏便に済ませたい」という現場の空気は、前例踏襲を美徳とする公立学校の構造的な病理そのものだった。教員たちは多忙を極め、新たなトラブルの噴出を恐れる。いじめという不都合な真実から目を背け、若者特有のじゃれ合いという言葉で矮小化することで、自分たちの平穏を守ろうとしていたのだ。佐藤の言葉に同調する教員も少なくなかった。

だが、青木の胸のうちは重く沈んでいた。果たして、これが単なるプロレスごっこなのだろうか。生徒が登校できなくなり、医師の診断書が出されている。いじめ防止対策推進法が定義する「いじめ」とは、児童生徒に対して、当該児童生徒が在籍する学校に在籍している等、一定の人間関係のある児童生徒が行う心理的又は物理的な影響を与える行為であり、当該行為の対象となった児童生徒が心身の苦痛を感じているものである。被害児童が苦痛を感じ、現に学校生活に支障を来している以上、主観的な加害側の意図に関わらず、それは厳然たる「いじめ」にほかならなかった。

しかも、問題の本質はそれにとどまらない。これが「重大事態」に該当するのではないかという強い疑念があった。いじめ防止対策推進法第二十八条第一項は、いじめにより当該学校に在籍する児童生徒の生命、心身又は財産に重大な被害が生じた疑いがあると認めるとき、又は、相当の期間学校を欠席することを余儀なくされていると認めるときは、学校の設置者又はその学校は、速やかに、組織を設けて調査を行うものと規定している。年間三十日を目安とするまでもなく、「相当の期間」の欠席、そして医師による診断書と心身の不調は、客観的に見て重大事態の要件を満たすか、少なくともその強い「疑い」がある状態に他ならなかった。

「このまま学年主任の言う通り、校内で『指導済み』として処理してしまえば、教育委員会への報告義務を怠ることになり、隠蔽と判断されかねない。しかし、組織的な調査に踏み切れば、校内に波風が立ち、教職員との間に大きな亀裂が入るかもしれない……」

青木は苦悩の末、受話器を手に取り、教育委員会へ直通のダイヤルを回した。個人的な信頼関係のある生徒指導担当の黒田指導主事の声を聴いた瞬間、張り詰めていた糸が切れそうになったが、管理職としての誇りがそれを踏みとどまらせた。

✦ ✦ ✦

「青木先生、お電話ありがとうございます。今お時間よろしいでしょうか」
受話器の向こうから聞こえてきた黒田の落ち着いた声に、青木は深く息を吐き出し、現在の状況をありのままに報告した。男子生徒の連続欠席、保護者からの訴え、そして学年主任をはじめとする教員たちの「プロレスごっこ」という認識のズレ、さらには重大事態への該当性をどのように判断すべきか迷っている胸中を、包み隠さず吐露した。

しばらくの沈黙の後、黒田は凛とした、しかし温かみのある口調で語り始めた。
「青木先生、率直に申し上げます。その状況は、文部科学省のガイドラインやいじめ防止対策推進法の趣旨に照らし合わせても、放置すれば致命的な法的不作為となります。『プロレスごっこ』という主観的な解釈は、いじめの定義から完全に外れています。大切なのは、加害生徒がどう思っていたかではなく、被害生徒がどう受け止め、どんな心身の苦痛を感じているか、そして実際に『相当の期間』学校を欠席せざるを得ない事態に陥っているかという客観的な事実です」

黒田の言葉は、青木の心の迷いを鋭く切り裂いていった。
「しかし、黒田先生、学年主任は校内で穏便に解決したいと……。下手に重大事態として調査委員会を立ち上げると、教職員の反発も予想されますし、保護者との交渉もさらに硬化するのではないかと恐れています」

受話器の向こうで、黒田は静かに首を振っているかのように、言葉に重みを込めた。
「青木先生、学校現場の『穏便に済ませたい』という心理が、これまでどれほどの重大な見落としや二次被害を生んできたか、先生ご自身が一番よくご存じのはずです。地方公務員法上の職務専念義務や信用失墜行為の防止、そして校長としての法的な責任において、子どもを守るための決断をためらってはなりません。いじめ防止対策推進法第二十二条に基づく『学校いじめ対策組織』をただちに機能させ、同法第二十八条第一項に定める重大事態の調査に着手すべきです。これは校長の裁量事項ではなく、法律上の義務なのです」

「義務……ですか」
「はい。法は、『疑いがあると認めるとき』に調査を行わなければならないと定めています。『重大かどうかわからないから調査しない』のではなく、『重大な被害が生じた疑いがある』からこそ、客観的な事実関係を明らかにするために調査組織を動かすのです。調査をした結果、いじめではなかったと判明するのであればそれはそれで結構ですが、最初から『大したことない』と切り捨てることは、法治国家の教育機関として許されません」

黒田の法規に裏打ちされた明確なアドバイスは、青木の背骨に鋼鉄のような芯を通した。そうだ、校長の仕事は教職員の機嫌を取ることでも、波風を立てずにやり過ごすことでもない。目の前で深く傷つき、学びの場を奪われている一人の子どもを守り抜くことだ。そのための権限と責任が、法律によって校長に与えられているのだ。

「よく分かりました、黒田先生。ありがとうございます。明日、直ちに管理職の緊急会議を開き、学年主任の認識を改めさせます。そして、いじめ防止対策推進法第二十八条に基づく調査組織の立ち上げを正式に決定し、教育委員会への第一報および今後の対応について正式に協議を申し入れます」

「そのご決断、心より支持いたします。教育委員会としても、調査委員会の構成や第三者の選任など、全面的にバックアップします。青木先生、学校のトップとして、毅然と進んでください」

電話を切った青木の後ろ姿には、先ほどまでの迷いは微塵もなかった。窓の外の夜空には、冷たくも澄んだ星が瞬いていた。法と正義を盾に、子どもと学校を守り抜く。校長としての真の闘いが、今、静かに始まろうとしていた。

✦ ✦ ✦

翌朝、職員会議室。青木は厳しい表情で、学年主任の佐藤を含む主要教職員の前に立っていた。机の上には、いじめ防止対策推進法の条文と、文部科学省のガイドラインが印刷された資料が一人ひとりに配られている。

「皆さん、おはようございます。昨夜、私は教育委員会と協議し、現在二年生で起きている一連の欠席事案について、重大事態の疑いがあるものとして、いじめ防止対策推進法第二十八条に基づく調査を実施することを決定しました」

会議室に、どよめきが走った。佐藤が慌てて立ち上がり、声を荒らげた。
「校長先生、ちょっと待ってください！ だからあれはプロレスごっこで、大げさだと言ったはずです。そんな大がかりな調査なんてしたら、学校中が大騒ぎになって、かえって収拾がつかなくなりますよ！」

青木は目をそらさず、佐藤をまっすぐに見据えて毅然とした声で言い放った。
「佐藤先生、それは教育者の言葉ではありません。いじめの有無や重大性の判断は、教職員の主観や『これまでの慣例』で行うものではありません。法律が求めているのは、客観的な事実と、子どもが受けている心身の苦痛への真摯な向き合い方です。私たちは子どもを守るためにここにいる。法に基づき、公正かつ客観的な調査を行います。教職員一丸となって、この問題から逃げずに立ち向かいます」

その圧倒的な気迫と、法規に裏打ちされた揺るぎない決意の前に、佐藤は気圧されたようにゆっくりと席に座り込んだ。他の教職員たちも、青木の真剣な眼差しを受け止め、次第に表情を引き締めていった。

逃避ではなく、直視。隠蔽ではなく、公正。
青木は窓の外を見つめながら、学校の最終責任者としての覚悟を胸の奥深くで改めて固めた。法を味方に、子どもたちの未来を守り抜く。そのための第一歩が、今、確実踏み出されたのだった。

【作中法規・教育法制のやさしい解説（Legal Commentary）】

物語の舞台となった中学校現場における「いじめの重大事態」の判断と対応は、学校経営および教育法務において極めて重要な局面です。ここでは、作中に登場した法律・法規の趣旨と、学校管理職（校長）および教職員が留意すべき実務上のポイントを解説します。

  1. いじめ防止対策推進法における「いじめ」の定義（第2条）
    - 本法におけるいじめは、児童生徒に対して、当該児童生徒が在籍する学校に在籍している等、一定の人間関係のある児童生徒が行う心理的又は物理的な影響を与える行為（インターネットを通じて行われるものも含む）であって、当該行為の対象となった児童生徒が心身の苦痛を感じているものを指します。
    - 現場でありがちな「プロレスごっこ」「じゃれ合い」「子ども同士のことだから」という主観的な免罪符は、法律上一切通用しません。被害児童が「心身の苦痛を感じている」という客観的・主観的事実が存在する限り、それは「いじめ」として厳格に扱われなければなりません。

  2. 学校いじめ対策組織の設置（第22条）
    - 学校は、いじめの防止等の対策を実効的に行うため、校長、教職員、心理医や福祉の専門家等の関係者により構成される「学校いじめ対策組織」を置くものとされています。日常的な情報共有だけでなく、いじめの早期発見や事案発生時の初期対応を組織的かつ機動的に行うための司令塔となります。

  3. 重大事態の調査義務（第28条）
    - 本条第一項では、以下のいずれかに該当する場合を「重大事態」と定めています：

    1. いじめにより当該学校に在籍する児童生徒の生命、心身又は財産に重大な被害が生じた疑いがあると認めるとき。
    2. いじめにより当該学校に在籍する児童生徒が相当の期間学校を欠席することを余儀なくされていると認めるとき（年間30日を目安としつつ、心身の状況等に応じて総合的に判断）。
      - ここで重要なのは、「重大な被害が生じた『疑い』があるとき」という点です。事実関係が確定していなくても、疑いの段階で速やかに組織を設けて調査を行う義務が学校（および学校設置者）に課されています。校長の裁量で「大したことない」と判断して調査を見送ることは、明確な法令違反となります。

  4. 学校の最終責任者である校長の法的責任
    - 学校教育法第37条等に基づき、校長は校務を整理し、所属職員を監督する責任を負います。不都合な事実を隠蔽したり、現場の「穏便に済ませたい」という事なかれ主義に迎合したりすることは、地方公務員法上の職務専念義務違反や信用失墜行為に該当するリスクを伴います。法規に基づいた客観的かつ毅然とした判断こそが、子どもを守り、学校の信頼を維持する唯一の道です。
