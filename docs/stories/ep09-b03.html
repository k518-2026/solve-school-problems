ハサミと模造紙を捨てた夜――500通の声を読み解くPythonテキストマイニング

🏷️ カテゴリ・領域：データ処理・Python/テキスト処理（Google フォーム集計 / Python (Pandas, OpenPyXL) / 日本語形態素解析 / キーワード出現頻度・可視化）
👥 登場人物：年配教諭・吉岡先生（教職26年目・PTA担当） × 若手教諭・小林先生（教職2年目・数学担当）
💡 解決フレームワーク：Google Forms ＋ Python（Pandas, 形態素解析）によるキーワード抽出と意見分類の自動化

11月中旬の午後7時。静まり返った職員室の片隅で、教職26年目を迎える教諭の吉岡は、老眼鏡の奥の目をしばたたかせながら溜息をついた。

「よし、これで『登下校の安全』に関する意見は32件目か……いや待てよ、これは『公園での遊び方』だから地域のマナーの分類に入るかな」

吉岡の大きな机の上は、足の踏み場ならぬ「手

の置き場」さえない状態だった。広げられた何枚もの模造紙。そこには「交通安全」「施設・設備」「PTA行事」「学習・ICT活用」といった見出しが黒の太字マジックで書かれている。その周囲には、プリントから切り出された細長い紙片が山をなし、吉岡の手には黄色とピンクの蛍光ペン、そして使い古されたステンレスのハサミが握られていた。

全校児童500世帯を対象に実施した「学校教育と地域連携に関するPTAアンケート」。吉岡は今年度のPTA担当として、保護者から寄せられた膨大な意見をまとめ、来週のPTA合同役員会で報告する資料を作成しなければならなかった。

前任の担当者から引き継いだやり方は極めてアナログだった。回収された紙のアンケートから自由記述欄をハサミで1行ずつ切り抜き、内容を目で読んで分類し、それぞれの模造紙にのりで貼り付けていく。最後に各模造紙の紙片を数えて集計し、Wordで清書する――気の遠くなるような作業だ。

「吉岡先生、まだ残られていたんですか？」

声をかけてきたのは、教職2年目で数学科を担当する若手教員の小林だった。ノートパソコンを腕に抱え、退勤の挨拶をしようとした小林は、吉岡のデスクを見て思わず足を止めた。

「おや、小林先生。お疲れ様。いやあ、保護者の皆様からの熱心なご意見が集まりすぎてね。ありがたいことなんだが、仕分けが終わらなくて」

吉岡は力なく笑い、額の汗を拭った。

「これ……全部ハサミで切って、手作業で分類されているんですか？」

小林は驚きを隠せない様子で、山積みになった紙片を見つめた。

「そうなんだよ。保護者の方がわざわざ書いてくださった生の声だからね。いい加減に扱うわけにはいかない。でも、文章によっては『通学路の街灯が暗くて危険だし、放課後クラブの指導も充実させてほしい』みたいに、複数の要素が混ざっているものも多くてね。どれに貼り付けるべきか迷ってしまって、なかなか進まないんだ」

吉岡の言葉には、長年教育現場で子どもや保護者と誠実に向き合ってきたベテランならではの情熱と温かさが滲み出ていた。しかし、その表情には明らかな疲弊の色が浮かんでいる。

小林は抱えていたパソコンを近くの空きデスクに置くと、吉岡の隣に椅子を引き寄せて座った。

「吉岡先生の『保護者の声を1つも無駄にしたくない』という思い、本当に頭が下がります。……ですが、先生、この作業、コンピュータの力を借りれば今夜のうちに、しかももっと正確に終わらせることができますよ」

「えっ？ コンピュータで？ でも小林先生、これは手書きの文章を文字起こししたテキストデータなんだよ。数字の集計ならExcelでできるかもしれないが、こういう『文章の仕分け』なんて、人間が読んで判断するしかないんじゃないのかい？」

吉岡は不思議そうに首をかしげた。実は吉岡も、業務のデジタル化を完全に拒絶していたわけではない。今回のアンケートでは、入力作業が得意な非常勤職員の力を借りて、紙で回収した500通の自由記述テキストをすでに1つのCSVファイル（テキストデータ）としてパソコンに入力し終えていたのだ。しかし、そのあとの「分類と集計」をどうしていいかわからず、結局プリントアウトしてハサミを入れるという従来の方法に逆戻りしていたのだった。

小林は吉岡の言葉に優しく微笑み、吉岡のパソコン画面に保存されている「アンケート回答_自由記述.csv」を指さした。

「文章の仕分けこそ、最新のデータ処理技術が得意とするところなんです。Pythonというプログラミング言語と『日本語形態素解析』という技術を使えば、500件の文章を一瞬で単語に分解し、頻度の高いキーワードを抽出して自動でカテゴリ分けができます。さらに、次回からは紙のアンケートではなく『Google Forms』を使えば、集計データがリアルタイムでそのままクラウドに蓄積されるので、最初の入力作業すらゼロにできますよ」

「パイソン……？ 形態素解析……？」

聞き慣れないカタカナに目を白黒させる吉岡に対し、小林は手元のノートパソコンを開き、キーボードを軽やかに叩き始めた。

「まず、次回からの運用の話を少しさせてくださいね。Google Formsを使えば、保護者の方はスマートフォンから簡単に回答できます。集計結果はGoogleスプレッドシートに自動的に集約されるので、回答が集まった瞬間にデータの整理が完了するんです。セキュリティ面でも、文部科学省のガイドラインに沿ったGoogle Workspaceの認証基盤を使っていますから安全です」

「なるほど、スマホで回答できれば保護者の方も書く手間が省けるかもしれんな。しかし小林先生、今ここにある500件のデータはどうなるんだい？」

「お任せください。今、吉岡先生が作ってくださったCSVデータを読み込んで、自動解析するPythonプログラムを動かします」

小林は画面上にコードエディタを立ち上げた。そこには数行の綺麗なプログラムが並んでいた。

import pandas as pd
from janome.tokenizer import Tokenizer

df = pd.read_csv('アンケート回答_自由記述.csv')

# 単語の抽出とカテゴリ自動判定の処理

「吉岡先生、日本語は英語と違って単語と単語の間にスペースがありませんよね。だからコンピュータにはどこが意味の区切りかわかりにくいんです。それを『名詞』や『動詞』といった最小の単位（形態素）に分解してくれるのが、このJanomeという形態素解析ライブラリです。そして、Pandasというデータ処理ライブラリを使って、分解した単語の出現回数を集計し、特定のキーワードが含まれる回答に自動でカテゴリタグをつけます」

「文章を単語に分解して、自動でタグをつける……！」

吉岡は老眼鏡の位置を直しながら、小林の画面を食い入るように見つめた。

「そうです。たとえば『通学路』『信号』『街灯』という言葉が含まれていれば『登下校・安全』に分類し、『体育館』『遊具』『エアコン』なら『施設・設備』に分類するルールをプログラムに組み込みます。しかも、1つの回答に複数のキーワードが含まれていれば、両方のカテゴリに重複カウントすることも可能です。手作業でハサミで切っていたら、紙を2枚複製しなければならなかった作業ですね」

「おお……！ 確かに、ひとつの文章に『通学路が危険で、体育館のエアコンも直してほしい』と書いてある意見があって、どっちの模造紙に貼るか悩んでいたんだよ！」

吉岡の目が輝き始めた。小林はターミナル画面を開き、コマンドを入力してエンターキーを押した。

「それでは、実行します」

画面上で文字が瞬時に流れていく。わずか3秒後、画面に「処理が完了しました：アンケート解析結果.xlsx」というメッセージが表示された。

「え……？ もう終わったのかい？」

吉岡が信じられないといった声をあげる。小林は生成されたExcelファイルをダブルクリックして開いた。

そこには、見事に整理されたデータが広がっていた。第1シートには、500件の回答が「登下校・安全」「施設・設備」「学習・ICT」「PTA活動・地域」といったカテゴリ別に自動分類され、それぞれの回答件数が棒グラフと円グラフで一目瞭然に可視化されていた。

さらに第2シートを開くと、全回答の中で頻繁に使われている重要単語（「通学路」「街灯」「宿題」「タブレット」「挨拶」など）が、出現頻度の高い順にランキング形式で一覧表示されていた。

「すごすぎる……！ 私が丸二日かけて半分も終わらなかった作業が、たった数秒で……。しかも、グラフレポートまで綺麗に出来上がっているじゃないか！」

吉岡は画面を指さしながら、思わず声を張り上げた。

「吉岡先生、ここを見てください」

小林はExcelのシートをスクロールし、特定の行をハイライトした。

「『登下校・安全』のカテゴリに入っている回答の中で、最も頻出している単語は『東門の交差点』でした。手作業だと全体の中でどれくらい重要な課題か感覚的になりがちですが、こうしてテキストマイニングを行うと、『500件中78件が東門の交差点に言及している』という客観的なデータとしてPTA役員会に提示できます」

吉岡は深く感銘を受けた様子で、静かに頷いた。

「客観的なデータ……まさにその通りだね。これまでは『保護者からこんな声がありました』と感覚で伝えていたけれど、これなら『全回答の15％がこの問題を指摘しています』と説得力を持って行政や警察に改善を要望できる。小林先生、これは単なる省力化じゃない。保護者の切実な声を、より強く、正確に届けるための素晴らしい武器だ」

吉岡の言葉に、小林の胸も熱くなった。自分が持つITの知識が、ベテラン教員が長年培ってきた教育的着眼点や保護者への深い思いやりと結びついた瞬間だった。

「吉岡先生が、回答のテキスト化をあらかじめ進めてくださっていたからこそ、このプログラムがすぐに活きたんです。先生のデータに対する誠実さのおかげですよ」

「ハハハ、お世辞でも嬉しいね。だがこれで、ハサミと模造紙の時代は終わりだな。小林先生、来年度からは最初からGoogle Formsを使ってアンケートを実施しよう。私にもそのフォームの作り方や、クラウドでの集計方法を教えてくれないか？」

「もちろんです！ 明日の放課後、Google Formsの作成手順とスプレッドシート連携の講習会を職員室で開きましょうか。他の先生方も絶対に喜ぶと思います」

翌週のPTA合同役員会。会議室のスクリーンには、吉岡が作成した鮮やかなアンケート分析レポートが映し出されていた。

「今年度の保護者アンケートでは、全校世帯の98％にあたる490件から回答をいただきました。テキスト解析の結果、最も関心が高かったのは『東門交差点の安全対策』で、全体の16％を占めています。次いで『校庭の遊具の修繕』が12％でした。これらデータに基づき、市教育委員会および所轄の警察署へ提出する要望書を作成いたしました」

整然としたデータと明確な根拠に基づく吉岡のプレゼンテーションに、PTA役員たちからは大きな感嘆の声と拍手が湧き起こった。役員会の会長が微笑みながら発言した。

「吉岡先生、毎年アンケートの集計は大変だと伺っていましたが、今年はこんなに分かりやすく、スピーディーに結果を出していただいて感謝いたします。データに基づいているので、私たち保護者も説得力を感じます」

「ありがとうございます。実は、本校の若い小林先生が最新のデジタル技術を教えてくれましてね。テクノロジーの力で、皆様の貴重な声をより正確に整理することができました」

吉岡は会議室の後ろで静かに見守っていた小林に向かって、温かく頷いて見せた。小林もまた、深く礼を返した。

会議が終わり、夜の職員室。吉岡のデスクの上はすっきりと片付き、新しいデュアルディスプレイが置かれていた。吉岡は老眼鏡をかけ、小林に教わったGoogle Formsの作成画面に向かって熱心にキーボードを叩いている。

「小林先生、来月の校外学習の保護者同意書も、Google Formsで作ってみたんだが、ちょっと見てくれるかい？」

「拝見します！ おお、吉岡先生、必須項目の設定もバリデーション（入力チェック）もバッチリですね！ 完璧です」

「ふふふ、若い先生方から技術を学ぶのは本当に楽しいよ。校務DXというのは、作業を楽にするだけじゃないんだな。浮いた時間で子どもたちと話したり、保護者の本当の思いにじっくり耳を傾けたりするためのものなんだと、今回の件でよく分かったよ」

吉岡の満足そうな笑顔に、職員室の温かな蛍光灯の光が優しく降り注いでいた。時代のバトンは、確かなリスペクトとともに若手からベテランへ、そしてベテランから教育の未来へと引き継がれていくのだった。

【作中技術・ITネットワークのやさしい解説（Technical Commentary）】

作中で小林先生が活用したテクノロジーと、今後の学校現場で応用できる校務DXの仕組みについて、ITが苦手な方にもわかりやすく解説します。

1. Google Formsによるアンケート収集とクラウド自動集計

従来、紙で実施していたアンケートをGoogle Forms（Google フォーム）に置き換えることで、以下のメリットが得られます。
- 入力作業の完全自動化: 保護者がスマホやPCから回答を入力すると、クラウド上の「Google スプレッドシート」にリアルタイムでデータが反映されます。転記ミスや打ち込みの負担がゼロになります。
- 回答漏れの防止: 「必須項目」を設定できるため、未記入での提出を防ぐことができます。
- セキュリティとアクセスコントロール: 学校で契約しているGoogle Workspaceアカウントを利用することで、アクセス権限を制限し、個人情報を安全に管理できます。

2. PythonとPandasによるデータ処理（データ分析）

Python（パイソン）は、データ処理や自動化に非常に適したプログラミング言語です。作中で使用されたライブラリ（便利な道具箱のようなもの）には以下の役割があります。
- Pandas（パンダス）: 大容量の表データ（CSVやExcel）を高速に読み込み、並び替え、抽出、集計するためのライブラリです。数千件のデータでも数秒で処理できます。
- OpenPyXL（オープンパイエクセル）: PythonからExcelファイル（.xlsx）を直接作成・編集し、グラフの挿入やセルの色付けなどを自動化するライブラリです。

3. 日本語形態素解析とテキストマイニング（Janome）

自由記述のような「文章データ」は、通常の数値集計（SUMやAVERAGE）では分析できません。そこで使われるのが「テキストマイニング」技術です。
- 形態素解析（Janome/Janome等）: 日本語の文章を「文法上の最小単位（形態素）」に分解し、品詞（名詞、動詞、形容詞など）を判定する技術です。
- 例：「通学路が暗くて危険です」⇒「通学路（名詞） / が（助詞） / 暗く（形容詞） / て（助詞） / 危険（名詞） / です（助動詞）」
- キーワード自動分類と頻度集計: 分解された名詞から「通学路」「街灯」「信号」などの重要単語をカウントし、特定のキーワードが含まれる回答に自動で「登下校・安全」といったタグを付与します。これにより、人の手で文章を読んで切り貼りする作業が不要になります。
