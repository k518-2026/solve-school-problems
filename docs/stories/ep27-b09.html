EPISODE #27 ・ [B09] 💻 パターンB：校務DX・ICT・ネットワーク

紙吹雪のパズルにサヨナラを――三者面談の重複を解き明かす「数式とGAS」の最適解

🏷️ カテゴリ・領域：三者面談・日程調整自動化（Google フォーム希望収集 / QUERY / FILTER / XLOOKUP 関数 / Google Apps Script 自動重複検知 / カレンダー自動登録）
👥 登場人物：教務主任・田辺先生（教職27年目） × 若手教諭・三浦先生（教職3年目・数学科）
💡 解決フレームワーク：Google フォーム ＋ スプレッドシート（QUERY / FILTER / XLOOKUP関数）とGASによる兄弟枠自動照合・日程割当アルゴリズム

十一月の放課後、窓の外は急速に帳を降ろし、冷たい秋風が校庭の木々を揺らしていた。

しかし、職員室の一角だけは、まるで真夏のような熱気に包まれていた。四台の事務机を強引に連結した特設スペース。その上には、色とり切りの「三者面談希望調査票」が、まるでモザイク画のように敷き詰められている。

「……あかん、またここでぶつかった。３年Ａ組の佐藤くんのお姉ちゃんと、１年Ｃ組の佐藤くんの弟。お母さんが同じ日に来校できるように時間をくっつけなあかんのに、１年Ｃ組の枠がもう埋まっとる」

教職二十七年目、教務主任の田辺先生は、老眼鏡を指先で押し上げながら、深くため息をついた。その手には、赤、青、黄の付箋と、何十回も書き直されてすり減ったシャープペンシルが握られている。

「田辺先生、まだやっておられたんですか」

声をかけたのは、教職三年目、数学科の三浦先生だった。手には温かい缶コーヒーを二つ持っている。

「おお、三浦先生。ありがとうな」

田辺先生はコーヒーを受け取り、こわばった肩を回した。

「毎年これだけは、どうしてもパズルが解けんでね。全校生徒六百人分。保護者の仕事の都合、部活動の予定、そして何より『兄弟姉妹』の重複調整や。兄が二階の教室で面談、その直後に一階の妹の教室へ移動できるように並べる。これが一枚でも狂うと、ドミノ倒しみたいに全員分が崩れてしまうんよ」

机の上には、担任たちが「うちのクラスはこれで決定！」と書き込んだ時間割が並んでいるが、そこへ「他クラスの兄弟との重複」という爆弾が投下されるたび、計画は白紙に戻る。すでに時刻は午後八時を回っていた。この作業のために、教務部と各学年主任は三日連続で徹夜に近い状態だった。

「こればかりはな、手作業でしかできんのよ」と田辺先生は自嘲気味に笑った。

「生徒一人ひとりの家庭環境や、保護者の仕事の都合を一番知っているのは担任やからね。機械に冷たく『この時間です』と割り振らせるわけにはいかんのや」

三浦先生は、机の上に散らばる紙の山を見つめ、静かに、しかし力強い声で言いました。

「田辺先生、その『温かい配慮』は絶対に崩しません。でも、その配慮を行き届かせるための『下準備』と『重複のチェック』なら、コンピュータにやらせた方が一瞬で、しかも正確に終わりますよ」

「え？ コンピュータにか？」

田辺先生が目を見開く。

「はい。ちょっと僕の画面を見てもらえますか」

三浦先生は自分のノートPCを開き、田辺先生の隣に置いた。画面に映し出されていたのは、見慣れたGoogleスプレッドシートだった。

✦ ✦ ✦

「まず、これが今年から導入したGoogleフォームの回答データです」と三浦先生は画面を指さした。

「ああ、保護者の皆さんにスマホから出してもらったやつやな。確かに、紙を回収してエクセルに打ち直す手間は減ったが……」

「ええ。でも、ただ集めるだけじゃもったいないんです。このスプレッドシートの裏側では、いくつかの数式と、僕が書いたプログラムが動いています。田辺先生、まずはこの『QUERY（クエリ）関数』と『FILTER（フィルター）関数』を見てください」

三浦先生が数式バーを示す。そこには、複雑な英語の関数が並んでいた。

「これは何をしてるんや？」

「この数式はですね、集まった六百人分の回答から、瞬時に『第一希望が月曜日の午後』『第二希望が火曜日の午前』というように、条件に合う生徒をクラスごとに自動で仕分けしているんです。さらに、右側の列にある『XLOOKUP（エックスルックアップ）関数』が、全校生徒の名簿から『同じ名字、かつ同じ保護者連絡先』のデータを自動で探し出して、兄弟姉妹のペアを特定しています」

「なんと……。じゃあ、誰と誰が兄弟なのか、いちいち生徒名簿をめくって突き合わせなくても、自動で紐付けされているということか？」

「その通りです」三浦先生は微笑んだ。

「そして、ここからが本番です。田辺先生たちが一番苦労されている『時間枠の重複』と『兄弟の連続配置』。これを解決するために、GAS（Google Apps Script）という簡単なプログラムを組みました。ボタンを一つ押すだけで、兄弟姉妹がいる家庭を優先的に抽出し、同じ日の連続する時間帯に自動で仮配置してくれます」

「自動で、仮配置……？」

田辺先生は、信じられないという表情で画面を見つめた。

「やってみますね。この『日程調整実行』という自作のボタンを押します」

三浦先生がマウスをクリックした。

画面上のスプレッドシートのセルが、まるで生き物のように激しく書き換わっていく。緑や黄色のカラーセラピーのような色彩がセルを埋め、わずか三秒後、画面の動きがピタリと止まった。

そこには、全校生徒の日程が美しく整列した表が完成していた。

「……え？」

田辺先生は老眼鏡を外し、目をこすって、もう一度老眼鏡をかけた。

「ちょっと待ってくれ。３年Ａ組の佐藤くんと、１年Ｃ組の佐藤くんは……」

「ここです」三浦先生がカーソルを合わせた。

「お姉ちゃんの面談が月曜日の十四時。弟さんの面談が同じ月曜日の十四時三十分。移動時間を考慮して、隣り合う枠に自動配置されています。もちろん、他のクラスの兄弟姉妹もすべて、同じ日に連続して配置されています」

「そんな馬鹿な……。私たちが三日間、頭を抱えて『あっちを動かせばこっちがズレる』とやっていたパズルが、一瞬で解けたというのか？」

「完璧に解けました」三浦先生は誇らしげに胸を張った。

「しかも、もし保護者から『やっぱりこの日は都合が悪くなった』と急な変更があっても、スプレッドシート上で時間を変更すれば、裏でプログラムが『重複検知アルゴリズム』を走らせます。もし他の兄弟と時間が重なったり、担任の面談可能時間を超えたりした場合は、このようにセルが真っ赤に光って警告してくれるんです」

画面の一部が、鮮やかな赤色に変化した。三浦先生がテスト用に時間を重複させると、即座にエラーが表示されたのだ。

「これなら……」田辺先生の声が震えていた。

「これなら、赤ペンでぐちゃぐちゃに書き直す必要もないし、せっかく決まった予定をまたひっくり返す恐怖に怯えなくてもいい。何より、担任が『本当に生徒と向き合うための準備』に時間を使えるじゃないか！」

✦ ✦ ✦

「でも、三浦先生」

田辺先生はふと、心配そうな表情を浮かべた。

「さっき、私は『機械の冷たい自動割り振りにしたくない』と言った。例えば、この２年Ｂ組の田中くんの家庭は、お母さんが夜遅くまで仕事をされている。だから、機械的に早い時間を割り振られてしまうと、面談に来られなくなってしまうんだ。そういう個別の事情は、どうなるんだい？」

三浦先生は、待っていましたとばかりに深くうなずいた。

「それこそが、田辺先生たちベテランの先生方の『経験と愛情』が必要な部分です。このシステムは、決して人間を排除しません。プログラムがやるのは、あくまで『誰もが納得する八割のベース作り』です。残りの二割は、田辺先生がシートを見ながら、手動でドラッグ＆ドロップして微調整してください。田中くんの枠を遅い時間に動かせば、システムが自動で他の枠をスライドさせ、破綻がないかだけをチェックしてくれます」

「なるほど！」

田辺先生はポンと手を叩いた。

「機械にすべてを支配されるのではなく、機械を道具として使いこなし、最後の仕上げを私たちがやる。これなら、私たちの『温もり』をシステムに組み込めるわけだ」

「その通りです。僕たち若手は、コードを書くことはできます。でも、どの家庭にどんな配慮が必要か、どの生徒がどんな課題を抱えているかという『生きた情報』は、田辺先生たちの経験には敵いません。技術と経験が合わさって初めて、最高の校務DXができるんです」

三浦先生の言葉に、田辺先生の胸が熱くなった。若者が自分たちの積み上げてきた教育技術をリスペクトし、その上で新しい武器を差し出してくれている。その協働の姿こそが、これからの学校に必要なのだと確信した。

「よし、三浦先生。さっそくこの『ハイブリッド調整法』で、全クラスの最終調整をやろう！ 私が個別の配慮が必要な家庭を指示するから、君がスプレッドシートを操作してくれ」

「喜んで！ 始めましょう！」

二人は机を並べ、作業を開始した。

「この子は部活のレギュラーだから、大会前のこの時間は避けてあげて」

「了解です。その時間帯をロックして、別の枠を自動検索します」

「このご家庭は日本語が少し苦手だから、通訳の先生が入れるこの時間帯に固定したい」

「FILTER関数で、通訳の先生の空き時間を抽出しました。ここに配置します」

かつてあれほど苦痛だった三者面談の調整作業が、今や小気味よいセッションのように進んでいく。キーボードを叩く軽快な音と、田辺先生の「おお、すごい！」「これなら完璧だ！」という歓声が職員室に響いた。

わずか一時間後、全校生徒六百人分の、誰一人として無理のない、そして兄弟姉妹の重複が完全に解消された「三者面談時間割」が完成した。

「終わった……本当に終わったぞ。まだ九時前だ」

田辺先生は、完成したシートを見つめ、信じられないといった様子で呟いた。例年なら、この時期は毎日終電近くまで残り、胃を痛めながらパズルを解いていたのだ。

「田辺先生、仕上げにこれを実行します」

三浦先生が画面の「確定・通知」ボタンを押した。

「これは何をするんだ？」

「このGASを実行すると、決定した面談日時が、各担任のGoogleカレンダーに自動で登録されます。さらに、保護者のメールアドレス宛に『面談日時決定のお知らせ』が、個別の時間枠を自動で挿入した状態で、一斉送信されます」

「印刷して、切って、生徒に配る手間までなくなるのか……！」

田辺先生は深く感嘆し、三浦先生の肩を叩いた。

「素晴らしいよ、三浦先生。君の技術は、私たち教員だけでなく、何百人もの保護者の時間と安心をも救ってくれたんだ」

「いえ。田辺先生が、生徒一人ひとりの家庭環境をすべて頭に入れておられたからこそ、このデータが『生きた時間割』になりました。僕の方こそ、勉強になりました」

窓の外を見上げると、いつの間にか雲が晴れ、満天の星が輝いていた。

静まり返った職員室で、二人は温かい缶コーヒーで小さく乾杯した。技術という新しい風が、学校の古い殻を優しく、しかし劇的に変えていく。その確かな手応えを感じながら、教務主任と若手数学教師は、晴れやかな笑顔で帰路についた。

【作中技術・ITネットワークのやさしい解説（Technical Commentary）】

作中で三浦先生が構築した「三者面談日程調整システム」は、Google Workspaceの標準機能を組み合わせることで、プログラミング初心者でも比較的容易に構築できる実用的な校務DXのモデルです。その仕組みをわかりやすく解説します。

1. Google フォームによる希望収集

従来の紙による回収では、「紛失リスク」「手入力による転記ミス」「集計の遅れ」が発生していました。Google フォームを活用することで、保護者がスマートフォンから直接入力したデータが、リアルタイムでGoogle スプレッドシートに自動集計されます。これにより、タイピングの手間が完全にゼロになります。

2. スプレッドシート関数によるデータの自動整理

集計された生の回答データを、以下の関数を用いて自動的に仕分け・連携します。

  • QUERY 関数: SQLに似た命令文を使い、大量のデータから「特定のクラスのみ」「特定の曜日を希望する人のみ」を瞬時に抽出します。
  • FILTER 関数: 指定した条件（例：「第1希望が月曜日」かつ「3年生」）に合致する行だけを絞り込んで別表に表示します。
  • XLOOKUP 関数: 従来の VLOOKUP の進化版です。生徒名や保護者の連絡先をキーにして、別シートにある全校名簿から「兄弟姉妹の有無」や「他のクラスに在籍する兄弟の氏名」を自動で検索・結合します。

3. GAS（Google Apps Script）による重複検知と自動配置

GAS（JavaScriptベースの簡易プログラム）を用いることで、スプレッドシートの標準機能だけでは難しい「複雑な条件分岐」を実行できます。

  • 兄弟姉妹の連続配置アルゴリズム:
1.全回答から「兄弟姉妹フラグ」が立っているペアを抽出する。
2.兄（姉）の希望時間枠を仮決定する。
3.その直後、または直前の時間枠に、妹（弟）のクラスの空き枠があるかをプログラムが探索する。
4.条件に合致する枠があれば、最優先で仮配置する。
  • リアルタイム重複検知:

スプレッドシートの「条件付き書式」やGASの onEdit() トリガー（値が書き換わった瞬間に実行されるプログラム）を利用し、同じ時間帯に同じ教員や同じ保護者が重複して配置された場合、該当セルを赤くハイライトして視覚的に警告します。

4. Google カレンダーおよびGmailとの自動連携

GASの最大の強みは、Googleの各サービス（スプレッドシート、カレンダー、Gmail）をシームレスに連携できる点にあります。

  • カレンダー自動登録: スプレッドシート上の「クラス」「生徒名」「日時」のデータを読み込み、担任のGoogleカレンダーに「三者面談：〇〇さん」という予定を自動で一括作成します。
  • Gmail一斉個別送信: 各保護者のメールアドレス宛てに、「〇〇様の面談時間は【11月15日 14:00〜】に決定しました」という個別最適化された案内メールを、プログラムから自動で一斉送信します。

このように、単に「手作業を自動化する」だけでなく、「教員の温かい配慮（手動調整）」を受け入れる余地を残したシステム設計にすることが、学校現場における校務DXを成功させる重要な鍵となります。
