EPISODE #56 ・ [B17] 💻 パターンB：校務DX・ICT・ネットワーク

失われた備品と静かなる革命――QRコードが紡ぐ図書室の再編

🏷️ カテゴリ・領域：図書室・教材在庫管理DX（QRコード自動生成（IMAGE関数） / タブレットカメラによる高速チェックイン / 貸出ステータス自動更新（GAS） / 棚卸し集計自動化）
👥 登場人物：図書主任・秋山先生（教職25年目） × 若手教諭・瀬戸先生（教職2年目・技術科）
💡 解決フレームワーク：バーコード/QRコード読み取り ＋ スプレッドシート在庫台帳による3秒貸出・未返却リマインド自動化

放課後の図書室は、埃っぽさと古い紙の匂いが混ざり合った独特の静寂に包まれていた。しかし、窓際の机で頭を抱える秋山先生の周囲だけは、その静寂とは裏腹に張り詰めた空気が漂っている。
「……また、この『理科実験器具・貸出記録』のノートが更新されていない……」
　秋山先生は、年季の入った老眼鏡を押し上げながら、分厚い手書きのノートをめくった。教職25年。彼はこれまで、この学校のあらゆる備品と図書の良き守護者として奔走してきた。しかし、近年の学級文庫の増加と、理科室の複雑な実験器具の流動化は、彼一人の記憶力と手書きの管理を限界へと追い込んでいた。
「先生、まだ終わらないんですか？」
　背後から声をかけたのは、若手教諭の瀬戸先生だった。技術科を担当する彼は、常に最新のデバイスを手に持ち、校内のネットワーク環境にも精通している。
「ああ、瀬戸先生。すまないね、少しだけ……。実は、去年の年度末の棚卸しで、高価な顕微鏡セットが三つも行方不明になったんだ。どのクラスに貸し出されたのか、誰が最後に持ち出したのか、記録が飛んでいる。このままじゃ、来年度の予算申請もままならないよ」
　秋山先生の声には、単なる事務作業への不満ではない、子供たちのための教材を失いたくないという、長年の教育者としての責任感が滲んでいた。

✦ ✦ ✦

「……なるほど。紙のノートでは『貸した』という事実だけは書けても、『今どこにあるか』という動態管理が追いつかないわけですね」
　瀬戸先生は秋山先生の隣に座り、ノートをじっくりと眺めた。彼は自身のタブレット端末を取り出し、画面を操作し始めた。
「先生、これ、全部手書きで追うのはもう限界ですよ。いいことがあります。私がちょっとだけ『仕組み』を作らせてください」
　秋山先生は少し疑わしそうな顔をしたが、瀬戸先生の真剣な眼差しに促され、頷いた。

翌週、図書室の風景は一変した。
　瀬戸先生は、Googleスプレッドシートを基盤とした在庫管理システムを構築した。彼はまず、全備品と図書のマスターデータを作成し、それぞれのIDに紐づくQRコードを自動生成した。
「これを見てください、秋山先生」
　瀬戸先生が画面を指さした。そこには、IMAGE関数を用いて、スプレッドシート上のデータからダイナミックに生成されたQRコードのリストが表示されていた。
「このQRコードを印刷して、各備品や図書セットに貼り付けるんです。貸し出す時は、生徒や担当者がタブレットのカメラでこれを読み取るだけです」
「えっ、それだけでいいのかい？ 複雑な入力はいらないのか？」
　秋山先生は驚いたように尋ねた。

瀬戸先生は微笑んで答えた。
「はい。QRコードをスキャンした瞬間、Google Apps Script（GAS）が作動して、スプレッドシートの『現在地』と『貸出ステータス』を自動で更新します。誰が、いつ、どのクラスに持ち出したか……それだけでいいんです」
　秋山先生は、瀬戸先生が示したデモを体験した。タブレットをQRコードにかざすと、画面上の「在庫状況：在校内」という文字が瞬時に「貸出中：2年A組」へと書き換わった。そのスピードと正確さに、秋山先生は思わず声を上げた。
「すごい……。まるで魔法だね」
「魔法というよりは、自動化の力です。そして何より、QRコード一つで『誰が持っているか』を可視化できることが一番のポイントです」

✦ ✦ ✦

システム導入から一ヶ月が経過した。
　図書室の受付には、瀬戸先生が用意した数台のタブレットと、QRコードのポスターが設置されていた。生徒たちは「スキャンするだけなら簡単だね」と笑いながら利用し、貸出・返却の手順は驚くほどスムーズになった。
　ある日の放課後、秋山先生は瀬戸先生を呼び止めた。
「瀬戸先生、見てくれ。先ほど2年B組の生徒が顕微鏡セットを返却しに来たんだ。スキャンした瞬間に、私の手元の管理画面も『返却済み』に変わったよ。あんなに悩んでいた『行方不明』という言葉が、最近この校内でほとんど聞かれなくなった」
　秋山先生の顔には、安堵と誇らしさが混じった笑みが浮かんでいた。
「これまでは、私が毎晩ノートを書き直して、頭の中でパズルを解くように備品の居場所を探していた。でも今は、システムがそれを代わりにしてくれている」

瀬戸先生は謙遜するように首を傾げた。
「秋山先生の『正確な管理をしたい』という熱意があったからこそ、このシステムは形になったんです。私はただ、その熱意を技術で支えただけですから」
　秋山先生は、若手の肩を軽く叩いた。
「いや、君の技術には本当に助けられたよ。でもね、瀬戸先生。技術があるのは素晴らしいことだが、それを使うのが『誰のためか』を常に考える気持ち……それは君も持っている。だからこそ、このシステムはうまく動いているんだ」

秋山先生は窓の外を見やった。
　かつて彼を苦しめた紙のノートの山は、今やデジタル上の整然としたデータへと昇華された。しかし、その中身にある「子供たちのための学び」という価値は、以前よりも鮮明に輝いているように見えた。
　図書室の静寂の中に、新しい時代の風が吹き抜けていた。

✦ ✦ ✦

【作中技術・ITネットワークのやさしい解説（Technical Commentary）】

本編では、アナログな管理業務をデジタル技術で解決する「校務DX」の典型的な手法を導入しました。以下に主要な技術要素を解説します。

  1. QRコードとIMAGE関数の活用
    QRコードは、特定のURLやテキスト情報を符号化したものです。Googleスプレッドシートでは IMAGE 関数を使用することで、セル内に画像を表示できます。今回は、備品IDを元にしたQRコードを自動生成することで、管理者の手動入力を極限まで減らす仕組みを想定しました。

  2. タブレットカメラによる高速チェックイン
    従来、貸出管理で最も時間がかかるのは「誰が何を借りたか」の入力作業です。タブレットのカメラ機能を活用することで、この入力を「スキャン（読み取り）」という動作に置き換えることができます。これにより、事務作業のストレスを大幅に軽減できます。

  3. Google Apps Script (GAS) による自動化
    GASは、Google Workspace（スプレッドシート等）と連携して動作するJavaScriptベースのスクリプトです。QRコードが読み取られた際に「誰が借りたか」「いつ返却されたか」という情報をバックエンドで処理し、スプレッドシートを書き換えます。この自動化により、人的ミスを防ぎ、リアルタイムでの在庫把握が可能になります。

  4. 動態管理とリマインドの仕組み
    「今どこにあるか」という動態管理は、DXの核心です。GASを利用すれば、「貸出から3日以上経過している備品がある場合、担任のメールアドレスに自動で通知を送る」といったリマインド機能も容易に実装可能です。これにより、年度末の棚卸しに向けた「探し回る時間」をゼロに近づけることができます。
